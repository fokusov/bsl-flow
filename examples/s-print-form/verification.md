# Проверка

Выполнена только офлайн-проверка артефактов скриптами BSL Flow: lint и final validation в новом временном проекте. Runtime 1С, загрузка конфигурации, открытие формы и печать не выполнялись.

Критерий runtime остаётся `BLOCKED`: для него нужна разрешённая тестовая база с проверенными метаданными и ролью пользователя.
