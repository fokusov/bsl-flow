# Synthetic/demo task: печатная форма заказа

Добавить для документа «Заказ покупателя» команду «Счёт на оплату». Команда формирует табличный документ из существующего макета, выводит номер и дату заказа, контрагента и строки товаров. Пустой табличный документ и отсутствие макета должны давать понятную диагностическую ошибку, без записи документа.

Это учебный fixture: реальная конфигурация, база и пользовательские данные не использовались.
