# Исходный запрос и допуск

12 сентября 2026 пользователь запросил завершить оставшиеся блокеры после поставки self-learning-memory, api-specification-council и repository-task-registry:

- поддержать реальный current-agent fallback Council на текущем Astra-хосте;
- реализовать native controller write slice, необходимый для `task activate`;
- реализовать явный перенос старых задач (`adopt`) с сохранением истории.

Точный запрос: «да, давай это все доработаем. также используй субагентов на gpt-luna».

Реализация и необходимые локальные проверки разрешены. Для отдельной живой проверки Astra пользователь разрешил до четырёх модельных вызовов суммарно. Этот лимит относится к проверочным запускам, не к запрошенной работе субагентов. Неопределённый результат не даёт разрешения на автоматический повтор.

Для продолжения перенесённой задачи пользователь явно выбрал: «После переноса явно перепривязать задачу и заново пройти проверки актуальности перед продолжением». UUID и история сохраняются; для операций с неопределённым исходом сначала требуется отдельная сверка. Автоматического продолжения старого процесса после copy нет.

Это продолжение ранее поставленного объёма. Предыдущие артефакты, грязное рабочее дерево и план архитектурного контекста сохраняются. Запрос не разрешает операции с базами 1С, снятие временного запрета durable Unica runtime, публикацию Git или изменение глобальной установки.

Полный переход всех поддерживаемых ОС на поставку без PowerShell остаётся отдельным migration milestone `native-cross-platform-cli`. Текущая задача должна обеспечить работающую активацию и продолжение задач, не выдавая частичный контроллер или проверку mock за полную готовность.
