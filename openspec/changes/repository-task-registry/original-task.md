# Исходный запрос

Пользователь хочет, чтобы задачи BSL Flow фиксировались как локальный проектный task tracker, вдохновлённый Backlog.md, но без полного копирования продукта.

Нужны команды CLI для просмотра всех задач проекта, включая завершённые, их статусов и подробностей конкретной задачи. Дополнительно согласованы:

- каталог охватывает весь Git-репозиторий и все его worktree;
- данные остаются локальными в конкретном клоне и не синхронизируются через Git;
- кроме controller-задач поддерживаются ещё не запущенные planned-задачи;
- planned-задача первой версии содержит title, description, priority, labels и dependencies;
- полезные идеи Backlog.md можно заимствовать как UX/контракты, но не переносить его архитектуру целиком.

Сначала требуется спецификация; реализация этой задачи текущим запросом не разрешена.
