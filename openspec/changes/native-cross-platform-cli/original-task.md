# Исходный запрос

Пользователь хочет переписать оставшиеся PowerShell-скрипты BSL Flow в собственный CLI и убрать зависимость от PowerShell, потому что коллеги работают на macOS и не должны устанавливать PowerShell.

Согласовано:

- миграция выполняется поэтапно, но конечная цель — ноль PowerShell;
- сначала устраняется runtime-зависимость пользователей, затем после доказанного parity удаляются legacy build/test scripts;
- обязательная матрица: Windows amd64, macOS arm64/amd64 и Linux amd64;
- перенос не должен создавать вторую state machine либо ослаблять существующие controller gates/recovery.

Сначала требуется спецификация; реализация этой задачи текущим запросом не разрешена.
