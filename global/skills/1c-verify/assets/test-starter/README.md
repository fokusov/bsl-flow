# Test starter assets

`yaxunit/ТестПилотДвижка.bsl` — минимальный модуль с фактически используемой регистрацией
`ЮТТесты.ДобавитьТест`. Положительный контроль запускается обычно; отрицательный существует,
но не зарегистрирован и нужен только для разовой проверки, что runner действительно сообщает
ошибку.

`yaxunit/ИнтеграцияСОткатом.recipe.bsl` намеренно не компилируется до привязки к реальному
проектному API. Он показывает обязательный контур: чтение исходного состояния, транзакция,
проверка внутри неё, откат при успехе и исключении, отдельное чтение после отката. Транзакция
не компенсирует внешние эффекты.

`yaxunit/ФикстураSafeMode.recipe.bsl` задаёт безопасную границу fixture: локальные значения
подставляются до компиляции в игнорируемую копию тестового расширения, а BSL получает только
структуру примитивов. В самой базе он не читает локальные файлы и не требует ослабления SafeMode.

`vanessa/pilot-engine.feature` — сохраняемая feature для проверки самого движка, не интерфейса
конфигурации. `ui-persisted-result.recipe.feature` — проектный рецепт: UI-изменение и readonly
проверка сохранённого результата должны быть разными шагами.
