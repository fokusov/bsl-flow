# Anchors, phases and defaults for 1c-estimate

Machine-readable single source: [anchors.json](anchors.json). This file explains semantics; on any conflict the JSON file wins because `Test-1CEstimate.ps1` reads only it.

## Что оценивают якоря

Якорь — стартовый диапазон **полной** трудоёмкости изменения для классификации S/M/L × риск low/medium/high, отдельно в человеко-часах (baseline `middle_3y`, полный цикл) и в агентных часах ИИ. Отправная точка, которую декомпозиция уточняет, а не заменяет: итог без сверки с якорем запрещён.

## Человеко-часы: состав полного цикла

Блоки и итог содержат **полноцикловые** часы: доля анализа, самотестирования, исправлений по ревью и инструкции уже включена в вилку блока, итог равен консервативной сумме блоков (спека, п.4–5). Доли фаз относительно ядра реализации:

| Фаза | Доля от ядра |
|---|---|
| Анализ по спеке | 0.15–0.20 |
| Реализация (ядро) | 1.00 |
| Самотестирование | 0.25–0.35 |
| Исправления по код-ревью | 0.15–0.25 |
| Краткая пользовательская инструкция | 0.05–0.10 |

Итого полный цикл ≈ 1.6–1.9 × ядро реализации. В `estimate.md` фиксируются фазы и множители, реально применённые при построении вилки блока.

## ИИ-часы: агентное время

Генерация + верификация + ремонты + ревью, wall-clock без ожидания ответов пользователя. Значения по умолчанию для `ai_basis` — константы этого скилла (`ai_defaults` в anchors.json): модель `gpt-6-astra`, effort `medium`, ожидаемое число попыток 1–4. Они не читаются из `bsl-flow.yaml` (единого ключа worker-модели там нет); если пользователь назвал иную модель/усилие — записывается названное.

## Свежесть якорей

Первые версии диапазонов намеренно консервативны и не откалиброваны фактическими данными; уточнение — только после накопления `actuals` завершённых задач. Неопределённость якорей сама по себе является драйвером вилки и поводом не завышать уверенность.

## Модификаторы ИИ-якоря по флагам запроса

Базовые ИИ-якоря откалиброваны на типовые задачи; некоторые признаки запроса детерминированно их утяжеляют. Если строки `fork_drivers` оценки содержат флаг из `ai_anchor_modifiers` в [anchors.json](anchors.json), обе границы **ИИ-якоря** умножаются на `ai_multiplier` этого флага (флаги складываются мультипликативно); человеческие якоря не меняются. На 2026-09: `external_artifact` → ×2.0 (парсер внешнего формата: одна успешная агентная попытка может занимать весь верх немодифицированного якоря), `posting` → ×1.5. Валидатор применяет модификаторы до расчёта расхождения и печатает эффективный якорь (`anchor_effective_ai`, `anchor_flags_applied`) в результате. Уточнение множителей — по накапливаемым `actuals`.

## Порог расхождения с якорем

Существенное расхождение — отклонение **любой** границы итоговой вилки (human min/max, ai min/max) от соответствующей границы якоря (для ИИ-границ — с применёнными модификаторами) более чем на 30%: `|итог − якорь| / якорь > 0.30`. При существенном расхождении `estimate.md` обязан содержать раздел `## Расхождение с якорем`, причём каждая расходящаяся граница должна быть названа (например, `ai_min`) вместе со своим расчётным процентом; проценты, указанные в разделе, сверяются валидатором с вычисленными (допуск ±0.5 п.п. на округление). Раздел-отписка «остальные границы в пределах 30%» без чисел отклоняется.

## Округление

Человеко-часы и timebox — шаг 0.5 ч; ИИ-часы — шаг 0.25 ч. Псевдоточная дробность запрещена и отклоняется валидатором.
