# Задача

В общем модуле `ОбщегоНазначения`, функция `ПроверитьПревышениеЛимита(Сумма, Лимит)`,
ошибка сравнения: сумма, **равная** лимиту, не должна считаться превышением лимита —
превышением должна считаться только сумма, строго большая лимита. Сейчас равная лимиту
сумма ошибочно засчитывается как превышение.

Исправьте сравнение внутри функции. Правок вне
`CommonModules/ОбщегоНазначения/**` не требуется.
