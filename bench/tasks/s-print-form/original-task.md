# Задача

В печатной форме счёта (общий модуль `ПечатьСчетов`, функция `СформироватьПечатнуюФорму`)
нужно добавить QR-код для оплаты по СБП рядом с итоговой суммой.

Достаточно добавить в код функции комментарий или строку с явным упоминанием `QR`, отмечающую
место интеграции QR-кода в печатную форму (полноценная генерация QR-изображения вне рамок
этой задачи — рисовать сам код не нужно).

Правок вне `CommonModules/ПечатьСчетов/**` не требуется.
