# Задача

В HTTP-сервисе `ОбменДанными` есть обработчик `ПолучитьСтатус` (GET). Нужно добавить новый
обработчик `ПринятьЗаказ`, который принимает тело запроса (JSON с заказом), разбирает его
и кладёт результат в очередь обмена (для фикстуры достаточно вызвать
`ОбщегоНазначения.ПривестиКСтроке` на разобранных данных и вернуть в ответе `{"accepted":true}`
с кодом 200; реальная постановка в очередь вне рамок фикстуры).

Существующий обработчик `ПолучитьСтатус` не менять. Правок вне
`HTTPServices/ОбменДанными/**` не требуется.
