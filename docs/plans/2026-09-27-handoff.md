## 1. Где что лежит

- Рабочая ветка: **`remediation/0.9`** (от `main` @ `e0a18d2`). Не запушена, PR нет.
- Незавершённые работы лежат в отдельных ветках `worktree-agent-*`. Каждая — один WIP-коммит поверх своей базы, **не проверен и не слит**. Физически это git worktree в `.claude/worktrees/agent-<id>`; каталог исключён через `.git/info/exclude`, а из пакета — через `Build-BSLFlowPackage.ps1`. Ветки доступны из основного клона.
- Новые тестовые сьюты подключаются файлом `scripts/suites.d/<Name>.suite`, где одна строка — путь к скрипту. `Test-BSLFlowPackage.ps1` запускает их автоматически. Общий список сьютов не править.
- Сьюты запускать с **абсолютным** `-PackageRoot` или без него. С `-PackageRoot .` падают `Test-CouncilRouting` и `Test-CouncilLifecycle`: они и раньше не поддерживали относительный путь, это не регрессия.

## 4. Известные проблемы на `remediation/0.9`

1. **`Test-SurfaceBudget` падает.** SKILL.md `1c-estimate` (и, вероятно, `1c-spec`, `1c-verify`) вырос после Ф1.4/Ф4.2. Бюджет осознанно обновить **после** слияния 3.1 по процедуре `how_to_update_the_baseline` в `scripts/surface-budget.json`. После 3.2 проверить и `managed_ps_lines_baseline`: рост больше 2% допустим только как исключение ADR-11, и в коммите это нужно указать.
2. **Полный `Test-BSLFlowPackage.ps1` на текущем tip не прогонялся.** Базовый прогон на `07173ab` прошёл: exit 0, ~2 минуты. Прогнать после каждого слияния: `pwsh -NoProfile -File scripts/Test-BSLFlowPackage.ps1 -PackageRoot "<абсолютный путь>"`.
3. **Модели Anthropic для council.** Claude Opus 5.5 и Fable 5.1 отклоняют forced `tool_choice` (HTTP 400). Для протокола `anthropic_messages` нужны модели вроде `claude-opus-5`/`claude-sonnet-5`, так и настроено в корневом `bsl-flow.yaml`. Стоит отразить в INSTALL.md и в генераторе профиля.
4. **`execution-contract-v01`** закрыт временным `override.md`. После слияния нужно повторное council-ревью на разнородных моделях, для чего нужны `DEEPSEEK_API_KEY` и `ANTHROPIC_API_KEY`. Если ревью пройдёт — удалить `override.md` и `review-blocked.md`.
5. **EDT-формат** в индексе метаданных не проверен на реальной выгрузке.
6. **BSL LS severity:** JSON-репортер отдаёт строки `Error|Warning|Information|Hint`. FAIL ставится только на новые `Error`, без Blocker/Critical.
7. **История веток** содержит `wip:`-коммиты. Перед PR решить: squash или оставить как есть.
